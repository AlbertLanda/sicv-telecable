# Ficha del abonado — referencia visual

La ficha del cliente usa un shell operativo azul TELECABLE con barra superior y navegación lateral, un encabezado ejecutivo del abonado, una tarjeta destacada para la OT abierta, pestañas de navegación y un resumen en dos columnas.

Cuando la dirección principal tiene coordenadas GPS válidas, el resumen muestra un mapa embebido y un acceso directo a Google Maps. La ficha mantiene separada la orden administrativa inicial de la ficha técnica y no expone asignación manual de técnicos.
